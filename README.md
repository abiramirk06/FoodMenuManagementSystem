\# Food Menu Management System



A full-stack Food Menu Management System built using ASP.NET Core Web API, Entity Framework Core, SQL Server and Angular.



\## Technologies



\### Backend

\- C#

\- ASP.NET Core Web API

\- Entity Framework Core

\- SQL Server



\### Frontend

\- Angular

\- TypeScript

\- HTML

\- CSS



\## Architecture

Layered Architecture



\## Features

\- Add food items

\- View food items

\- Update food items

\- Delete food items

\- Filter by category

\- Filter by availability



\## Development Approach

Vertical Slice Development

In Development
